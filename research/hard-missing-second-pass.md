## Criterio

Se revisaron únicamente las referencias solicitadas y se excluyeron decants. Para marcar **APROBADO** se exigió coincidencia de marca, nombre, variante, concentración, formato y capacidad declarada; además, la URL directa se comprobó con respuesta HTTP 200 y contenido de imagen, y el packshot se inspeccionó visualmente. Cuando el renglón del proveedor no identifica una variante única, se mantuvo **SIN_REEMPLAZO** aunque existan imágenes parecidas.
